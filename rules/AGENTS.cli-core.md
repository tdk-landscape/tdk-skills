# TDK CLI core repository

This repository implements the TDK CLI, discovery system and Tilt engine. The user-facing CLI reference is `cli/README.md`; verify command behavior against the implementation before documenting or changing it.

## Working rules

- Keep CLI command behavior and user-facing output aligned with `cli/README.md` and the main README where relevant.
- Preserve the Project → Stack → Resource model and compatibility with existing project manifests.
- Treat generated `.autogenerated/` output as derived data. Update its source or generator, then regenerate and verify it.
- Follow the nearest `AGENTS.md`; engine and topology directories may define additional constraints.
- Keep changes focused. Do not modify benchmark/evaluation harnesses or weaken tests to make a feature pass.
- Run the narrowest relevant checks for changed code, then report what was run and any unverified areas.

## Documentation and skills

- Shared, reusable agent skills are maintained in <https://github.com/tdk-landscape/tdk-skills>.
- Update command documentation when a CLI command's flags, behavior or output changes.
- Do not copy the whole shared skill catalog into this repository. If a local mirror is needed, make it generated and document its sync source.
